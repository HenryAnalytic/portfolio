# Portfólio de Henry — Análise de Dados

Site estático feito com HTML, CSS e JavaScript, preparado para publicação no GitHub Pages.

## Arquivos
- `index.html`: conteúdo e estrutura do site.
- `style.css`: identidade visual, layout responsivo e animações.
- `script.js`: menu mobile, navegação ativa e efeitos de entrada.
- `assets/projects/`: coloque aqui as imagens reais dos seus dashboards quando estiverem prontas.

## Antes de publicar
1. Abra `index.html` no navegador para conferir o site.
2. No `index.html`, troque `seuemail@exemplo.com` pelo seu e-mail real.
3. Troque os links genéricos de LinkedIn e GitHub pelos seus perfis.
4. Revise os números ilustrativos e substitua as prévias por imagens reais dos projetos antes de divulgar o portfólio.
5. Publique os arquivos em um repositório GitHub e ative **Settings → Pages → Deploy from a branch → main / root**.

## Incorporar no Google Sites
O ideal é publicar primeiro o site no GitHub Pages e depois, no Google Sites, usar **Inserir → Incorporar → Por URL** e informar a URL publicada. A incorporação pode ficar limitada ao espaço e à altura do iframe; para a melhor experiência, compartilhe também o link direto do portfólio.

## Observação
As prévias de dashboards e os valores mostrados são elementos ilustrativos de design, não dados validados. Não os apresente como resultados reais. O portfólio deve ser revisado e personalizado antes de divulgação pública.
